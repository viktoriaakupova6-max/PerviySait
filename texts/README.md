# Тексты книг для чтения онлайн

Файл с именем `<id книги>.txt` автоматически подхватывается кнопкой «Открыть».

В папке 113 файлов (42 МБ): 89 полных текстов художественных произведений
(ещё 6 коротких стихотворений лежат в `js/texts.js`) и 24 онлайн-версии учебных,
справочных, краеведческих и методических изданий — учебный материал по курсу,
составленный библиотекой (полные тексты этих изданий защищены авторским правом).

Источник полных текстов — открытая библиотека ilibrary.ru через свободный набор
DanKertLit/dankertlit.github.io. Взяты только произведения в общественном
достоянии (авторы умерли более 70 лет назад), тексты очищены от сносок,
колонтитулов и разметки и разбиты на главы.

- `<id>` — поле `id` из `js/data.js`, например `pushkin-kapitanskaya.txt`.
- Формат — обычный текст в кодировке UTF-8.
- Строка, начинающаяся с `# `, — заголовок книги или главы (`# Глава 1`).
- Абзацы разделяются пустой строкой.
- Если абзац состоит из нескольких коротких строк — он выводится как строфа стихотворения.

Пример:

```
# Капитанская дочка

# Глава 1. Сержант гвардии

Был бы он хороший человек...
```

В каталоге сейчас нет изданий без текста: у всех 55 книг «Открыть» показывает
материал. Если добавить издание в `js/data.js` и не положить файл, читалка
покажет вежливое сообщение о том, что текст ещё не загружен, и шифр издания.
