# Тексты книг для чтения онлайн

Файл с именем `<id книги>.txt` автоматически подхватывается кнопкой «Читать».

- `<id>` — поле `id` из `js/data.js`, например `pushkin-kapitanskaya.txt`.
- Формат — обычный текст в кодировке UTF-8.
- Абзацы разделяются пустой строкой.
- Если абзац состоит из нескольких коротких строк — он выводится как строфа стихотворения.

Пример:

```
Глава первая

Сержант гвардии

Был бы он хороший человек...
```

Если текста нет ни в `js/texts.js`, ни в этой папке, читалка покажет
вежливое сообщение о том, что текст ещё не загружен.
