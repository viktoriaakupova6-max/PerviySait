# Онлайн-версия издания

«Справочник по физике» — настольное пособие для подготовки к занятиям, зачётам и экзаменам. В библиотеке колледжа несколько экземпляров (С-05). Онлайн-версия содержит основные формулы, единицы измерения, физические постоянные и справочные таблицы, которые чаще всего нужны студентам технических специальностей.

# Международная система единиц (СИ)

Основные единицы СИ: метр (м) — длина, килограмм (кг) — масса, секунда (с) — время, ампер (А) — сила тока, кельвин (К) — температура, моль (моль) — количество вещества, кандела (кд) — сила света.

Приставки: кило (к) — 10³, мега (М) — 10⁶, гига (Г) — 10⁹, милли (м) — 10⁻³, микро (мк) — 10⁻⁶, нано (н) — 10⁻⁹, пико (п) — 10⁻¹². Пример: 3,5 кВт = 3500 Вт; 20 мкм = 20·10⁻⁶ м = 0,02 мм.

Производные единицы: ньютон (Н) — сила, джоуль (Дж) — работа и энергия, ватт (Вт) — мощность, паскаль (Па) — давление, герц (Гц) — частота, кулон (Кл) — заряд, вольт (В) — напряжение, ом (Ом) — сопротивление, фарад (Ф) — ёмкость, тесла (Тл) — магнитная индукция.

# Физические постоянные

Скорость света в вакууме c = 2,998·10⁸ м/с. Гравитационная постоянная G = 6,67·10⁻¹¹ Н·м²/кг². Ускорение свободного падения g ≈ 9,81 м/с². Постоянная Авогадро N_A = 6,02·10²³ моль⁻¹. Универсальная газовая постоянная R = 8,31 Дж/(моль·К). Постоянная Больцмана k = 1,38·10⁻²³ Дж/К.

Элементарный заряд e = 1,6·10⁻¹⁹ Кл. Электрическая постоянная ε₀ = 8,85·10⁻¹² Ф/м. Магнитная постоянная μ₀ = 4π·10⁻⁷ Гн/м. Постоянная Планка h = 6,63·10⁻³⁴ Дж·с. Масса электрона 9,11·10⁻³¹ кг, масса протона 1,67·10⁻²⁷ кг.

Атомная единица массы 1 а.е.м. = 1,66·10⁻²⁷ кг. Энергия 1 эВ = 1,6·10⁻¹⁹ Дж. Нормальные условия: 0 °C и 101,3 кПа (760 мм рт. ст.).

# Основные формулы: механика

Равномерное движение: s = vt. Равноускоренное: v = v₀ + at; s = v₀t + at²/2; v² − v₀² = 2as. Свободное падение: h = gt²/2; v = gt.

Движение по окружности: v = 2πR/T; a_ц = v²/R = 4π²R/T²; ω = 2π/T. Второй закон Ньютона: F = ma. Импульс: p = mv. Работа: A = Fs·cos α. Мощность: N = A/t. Кинетическая энергия: E_k = mv²/2. Потенциальная энергия: E_p = mgh.

Трение: F_тр = μN. Упругость: F = kx, энергия пружины E = kx²/2. Закон всемирного тяготения: F = G·m₁m₂/r². Давление: p = F/S; гидростатическое p = ρgh; сила Архимеда F_A = ρ_ж·g·V.

# Основные формулы: теплота, электричество, оптика

МКТ: p = ⅓m₀nv²; pV = (m/M)RT; U = 3/2·(m/M)RT. Первое начало: Q = ΔU + A. КПД тепловой машины: η = A/Q₁; для цикла Карно η = (T₁ − T₂)/T₁. Влажность: φ = p/p_нас·100 %.

Постоянный ток: I = U/R; R = ρl/S; I = ε/(R + r); P = UI = I²R. Последовательное соединение: R = R₁ + R₂; параллельное: 1/R = 1/R₁ + 1/R₂. Электроёмкость: C = q/U; энергия конденсатора W = CU²/2.

Магнитное поле: F = BIl·sin α; F = qvB·sin α; Φ = BS·cos α; ε = −ΔΦ/Δt. Оптика: sin α/sin β = n; 1/F = 1/d + 1/f; D = 1/F; увеличение Γ = H/h = f/d.

# Как работать со справочником

Перед подстановкой чисел приведите все величины к единицам СИ. Проверяйте размерность результата. Округляйте ответ до значащих цифр, соответствующих точности исходных данных. Записывайте формулу, подстановку и ответ отдельными строками — так проще найти ошибку.

Помните: справочные значения даны для нормальных условий; при других температуре и давлении используйте поправки. Для инженерных расчётов берите данные из профильных справочников и стандартов, а не из учебных таблиц.
