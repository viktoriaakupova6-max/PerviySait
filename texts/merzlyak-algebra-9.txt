# Уравнения и системы уравнений

Квадратное уравнение ax² + bx + c = 0 при a ≠ 0 решают по формуле корней: x = (−b ± √D) / (2a), где дискриминант D = b² − 4ac. При D > 0 два корня, при D = 0 один, при D < 0 корней нет. По теореме Виета x₁ + x₂ = −b/a, x₁ · x₂ = c/a.

Приведённое уравнение x² + px + q = 0 удобно решать по обратной теореме Виета: если числа m и n таковы, что m + n = −p, а mn = q, то они являются корнями. Этот приём экономит время при подборе корней.

Уравнения, сводящиеся к квадратным: биквадратные (замена t = x²), дробно-рациональные (с обязательной проверкой знаменателя), уравнения с модулем. При решении дробно-рационального уравнения находят область допустимых значений и отбрасывают посторонние корни.

Системы уравнений решают способом подстановки, способом сложения и графически. Система двух линейных уравнений имеет единственное решение, если прямые пересекаются; не имеет решений, если прямые параллельны; имеет бесконечно много решений, если прямые совпадают.

# Неравенства и их системы

Квадратное неравенство ax² + bx + c > 0 решают методом интервалов: находят корни соответствующего уравнения, отмечают их на числовой прямой, определяют знак выражения на каждом промежутке (по знаку старшего коэффициента и чередованию). Ответ записывают в виде промежутков.

Метод интервалов применяют и для неравенств более высоких степеней и для дробно-рациональных неравенств. Важно помнить: при чётной кратности корня знак при переходе через точку не меняется; точки, обращающие знаменатель в нуль, всегда выколоты.

Система неравенств — пересечение решений; совокупность неравенств — объединение. Двойное неравенство a < f(x) < b равносильно системе из двух неравенств, его решают последовательными преобразованиями всех трёх частей.

# Функции и их графики

Функция y = f(x): каждому значению x из области определения соответствует единственное значение y. Способы задания: формулой, таблицей, графиком, словесным описанием. Свойства: область определения, область значений, нули, промежутки знакопостоянства, монотонность, наибольшее и наименьшее значения.

Изучаемые в 9 классе функции: линейная y = kx + b (график — прямая, k отвечает за наклон), обратная пропорциональность y = k/x (гипербола), квадратичная y = ax² + bx + c (парабола), y = √x, y = |x|, y = x³.

Квадратичная функция: вершина параболы x₀ = −b/(2a), y₀ = f(x₀); ветви направлены вверх при a > 0 и вниз при a < 0. Ось симметрии x = x₀. Нули функции находят решением уравнения f(x) = 0, промежутки знакопостоянства — по расположению параболы относительно оси Ox.

Преобразования графиков: y = f(x) + b — сдвиг вдоль оси Oy, y = f(x + a) — сдвиг вдоль оси Ox влево при a > 0, y = k·f(x) — растяжение вдоль Oy, y = f(kx) — сжатие вдоль Ox, y = −f(x) — симметрия относительно оси Ox.

# Арифметическая и геометрическая прогрессии

Арифметическая прогрессия задаётся первым членом a₁ и разностью d: aₙ = a₁ + d(n − 1). Сумма первых n членов: Sₙ = (a₁ + aₙ)·n / 2. Характеристическое свойство: каждый член, начиная со второго, равен среднему арифметическому соседних: aₙ = (aₙ₋₁ + aₙ₊₁)/2.

Геометрическая прогрессия задаётся первым членом b₁ и знаменателем q: bₙ = b₁ · q^(n−1). Сумма первых n членов при q ≠ 1: Sₙ = b₁(qⁿ − 1)/(q − 1). Характеристическое свойство: bₙ² = bₙ₋₁ · bₙ₊₁.

Сумма бесконечной геометрической прогрессии существует при |q| < 1 и равна S = b₁/(1 − q). Пример применения: обращение периодической десятичной дроби в обыкновенную.

Прогрессии применяются в задачах на сложные проценты, начисление вкладов, рост производства, а также в физике и геометрии.

# Элементы статистики и теории вероятностей

Статистические характеристики выборки: среднее арифметическое, медиана, мода, размах. Среднее арифметическое — сумма значений, делённая на их количество; медиана — значение, делящее упорядоченный ряд пополам; мода — наиболее часто встречающееся значение; размах — разность наибольшего и наименьшего значений.

Для больших выборок строят таблицы частот, полигоны и гистограммы; по ним судят о распределении данных. Относительная частота события равна отношению числа благоприятных исходов к общему числу испытаний.

Классическое определение вероятности: P(A) = m/n, где m — число исходов, благоприятствующих событию, n — число всех равновозможных исходов. Вероятность достоверного события равна 1, невозможного — 0, сумма вероятностей противоположных событий равна 1.

Комбинаторика: правило произведения, перестановки Pₙ = n!, размещения и сочетания. Эти формулы нужны для подсчёта числа исходов в вероятностных задачах.
