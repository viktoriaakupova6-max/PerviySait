Учебное пособие по алгебре и началам математического анализа для 10–11 классов. Соответствует примерной программе среднего общего образования: тригонометрия, степенные и показательные функции, логарифмы, производная и интеграл, комбинаторика и вероятность. # Тригонометрические функции

Радианная мера угла: 1 радиан — центральный угол, длина дуги которого равна радиусу. Соотношение: π радиан = 180°, отсюда 1° = π/180 ≈ 0,01745 рад, 1 рад ≈ 57,3°.

Синус и косинус определяют через точку единичной окружности: если точка M(x; y) получена поворотом начальной точки (1; 0) на угол α, то cos α = x, sin α = y. Тангенс tg α = sin α / cos α, котангенс ctg α = cos α / sin α.

Знаки функций по четвертям: в I четверти все положительны, во II — sin положителен, в III — tg и ctg, в IV — cos. Значения основных углов: sin 30° = 1/2, cos 60° = 1/2, sin 45° = cos 45° = √2/2, sin 90° = 1, cos 180° = −1.

Основное тригонометрическое тождество: sin²α + cos²α = 1. Формулы: 1 + tg²α = 1/cos²α; 1 + ctg²α = 1/sin²α. Формулы сложения: sin(α ± β) = sin α cos β ± cos α sin β; cos(α ± β) = cos α cos β ∓ sin α sin β. Формулы двойного угла: sin 2α = 2 sin α cos α; cos 2α = cos²α − sin²α = 1 − 2sin²α.

# Решение тригонометрических уравнений

Простейшие уравнения: sin x = a (|a| ≤ 1) → x = (−1)^n arcsin a + πn, n ∈ Z; cos x = a → x = ±arccos a + 2πk; tg x = a → x = arctg a + πk; ctg x = a → x = arcctg a + πk.

Сводящиеся уравнения: заменой переменной (например, 2cos²x − cos x − 1 = 0 относительно t = cos x), разложением на множители, однородные уравнения делением на cos x или cos²x, понижением степени через cos 2x.

Отбор корней на промежутке выполняют на окружности или через неравенства; ответ проверяют подстановкой. Практическое применение: описание колебаний (x = A sin(ωt + φ)), расчёт цепей переменного тока, геодезические измерения.

# Степенные, показательные и логарифмические функции

Корень n-й степени: (ⁿ√a)ⁿ = a; для чётного n a ≥ 0. Свойства степеней: aᵐ·aⁿ = aᵐ⁺ⁿ; aᵐ/aⁿ = aᵐ⁻ⁿ; (aᵐ)ⁿ = aᵐⁿ; (ab)ⁿ = aⁿbⁿ. Степень с дробным показателем: a^(m/n) = ⁿ√(aᵐ).

Показательная функция y = aˣ при a > 1 возрастает, при 0 < a < 1 убывает; область значений (0; +∞). Показательные уравнения сводят к равенству степеней с одинаковым основанием либо решают заменой переменной.

Логарифм: log_a b = c ⇔ aᶜ = b (a > 0, a ≠ 1, b > 0). Основное логарифмическое тождество a^(log_a b) = b. Свойства: log(xy) = log x + log y; log(x/y) = log x − log y; log xᵖ = p log x; переход к новому основанию log_a b = log_c b / log_c a. Десятичный логарифм lg, натуральный ln (основание e ≈ 2,718).

Логарифмическая функция y = log_a x обратна показательной; её график — отражение y = aˣ относительно прямой y = x. Применение: сложные проценты, расчёт времени распада и роста, шкала децибел, кислотность pH, сложность алгоритмов.

# Производная и её приложения

Производная функции в точке — предел отношения приращения функции к приращению аргумента при Δx → 0. Правила дифференцирования: (u ± v)' = u' ± v'; (uv)' = u'v + uv'; (u/v)' = (u'v − uv')/v²; сложная функция (f(g(x)))' = f'(g)·g'.

Таблица производных: (xⁿ)' = n·xⁿ⁻¹; (sin x)' = cos x; (cos x)' = −sin x; (tg x)' = 1/cos²x; (eˣ)' = eˣ; (ln x)' = 1/x; (aˣ)' = aˣ ln a; (log_a x)' = 1/(x ln a).

Геометрический смысл: производная равна угловому коэффициенту касательной, k = tg α = f'(x₀). Уравнение касательной: y = f(x₀) + f'(x₀)(x − x₀). Физический смысл: производная координаты по времени — скорость, производная скорости — ускорение.

Применение к исследованию функций: если f'(x) > 0 на промежутке, функция возрастает; если f'(x) < 0 — убывает. Точки, где производная меняет знак с плюса на минус, — максимум, с минуса на плюс — минимум. Наибольшее и наименьшее значения на отрезке ищут среди критических точек и значений на концах.

# Интеграл и площади

Первообразная F(x) функции f(x): F'(x) = f(x). Неопределённый интеграл ∫f(x)dx = F(x) + C. Таблица: ∫xⁿdx = xⁿ⁺¹/(n + 1) + C (n ≠ −1); ∫dx/x = ln|x| + C; ∫sin x dx = −cos x + C; ∫eˣdx = eˣ + C.

Формула Ньютона — Лейбница: ∫ₐᵇ f(x)dx = F(b) − F(a). Геометрический смысл — площадь криволинейной трапеции. Свойства: линейность, разбиение отрезка, смена знака при перестановке пределов.

Применение: вычисление площадей фигур, работы переменной силы, пути по графику скорости, объёма тела вращения, расхода жидкости. В технических расчётах интеграл используют для суммарных величин: масса при переменной плотности, заряд при переменном токе.

# Последовательности и прогрессии

Последовательность — функция, заданная на множестве натуральных чисел. Способы задания: формулой n-го члена, рекуррентно, словесно. Арифметическая прогрессия: aₙ = a₁ + d(n − 1), сумма Sₙ = (a₁ + aₙ)n/2, характеристическое свойство aₙ = (aₙ₋₁ + aₙ₊₁)/2.

Геометрическая прогрессия: bₙ = b₁qⁿ⁻¹, сумма Sₙ = b₁(qⁿ − 1)/(q − 1) при q ≠ 1, сумма бесконечной убывающей прогрессии S = b₁/(1 − q) при |q| < 1.

Применение: сложные проценты, банковские вклады и кредиты, рост производства, задачи на численность популяций, обработку данных. Пример: вклад 100 000 ₽ под 8 % годовых через 5 лет даёт 100 000 · 1,08⁵ ≈ 146 933 ₽.

# Комбинаторика, статистика и вероятность

Правило произведения: если выбор делается в два этапа (m и n вариантов), всего m·n вариантов. Перестановки Pₙ = n!; размещения Aⁿₖ = n!/(n − k)!; сочетания Cⁿₖ = n!/(k!(n − k)!). Свойство Cⁿₖ = Cⁿ⁻ᵏ.

Бином Ньютона: (a + b)ⁿ = Σ Cⁿₖ aⁿ⁻ᵏ bᵏ. Треугольник Паскаля даёт коэффициенты разложения.

Вероятность: классическое определение P(A) = m/n; сложение вероятностей несовместных событий, умножение для независимых. Формула полной вероятности и формула Байеса. Математическое ожидание, дисперсия и среднее квадратическое отклонение дискретной величины.

Статистика: выборка, генеральная совокупность, среднее, медиана, мода, размах, дисперсия; гистограмма и полигон частот. Нормальное распределение и правило трёх сигм — основа статистических выводов в технике и контроле качества.

# Итоговое повторение и подготовка к экзамену

План повторения: тождественные преобразования; уравнения и неравенства (линейные, квадратные, дробно-рациональные, показательные, логарифмические, тригонометрические); функции и графики; производная и её приложения; интеграл; вероятность.

Типичные ошибки: потеря корней при делении на выражение с неизвестным, неучёт области допустимых значений логарифма, неверный отбор корней тригонометрического уравнения, ошибки в знаках при дифференцировании сложной функции.
