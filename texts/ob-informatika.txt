# Онлайн-версия издания

Учебник И. Г. Семакина, Е. К. Хеннера «Информатика и ИКТ» (352 с., ОБ-08, 36 экземпляров) — базовый курс. Полный текст издания не публикуется; онлайн-версия содержит учебный материал по программе: информация и информационные процессы, алгоритмы и программирование, таблицы и базы данных, сети и информационная безопасность.

# Информация и информационные процессы

Информация — сведения об объектах и явлениях окружающего мира, уменьшающие неопределённость знания. Единицы измерения: бит, байт = 8 бит, Кбайт = 1024 байт, Мбайт = 1024 Кбайт.

Количество информации в сообщении равновероятных вариантов определяют по формуле Хартли: N = 2^i, где N — число вариантов, i — количество информации в битах. Алфавитный подход: объём текста = количество символов × информационный вес одного символа.

Информационные процессы: сбор, хранение, обработка, передача и защита данных. В компьютере информация кодируется двоичным кодом: число, текст (кодировки UTF-8, Windows-1251), графика (растровая и векторная), звук (частота дискретизации, разрядность), видео.

Системы счисления: позиционные (двоичная, восьмеричная, шестнадцатеричная) и непозиционные. Перевод из десятичной системы делением на основание, из двоичной в десятичную — по разрядам. Шестнадцатеричная запись удобна для представления байтов.

# Устройство компьютера

Архитектура фон Неймана: процессор, память, устройства ввода-вывода, принцип программного управления. Процессор состоит из арифметико-логического устройства и устройства управления; характеристики — тактовая частота, число ядер, кэш.

Память: внутренняя (ОЗУ, ПЗУ, кэш) и внешняя (SSD, HDD, флеш-накопители, оптические диски). ОЗУ энергозависима; ПЗУ хранит программу начальной загрузки. Периферия: клавиатура, мышь, монитор, принтер, сканер, плоттер, устройства связи.

Программное обеспечение: системное (операционная система, драйверы, утилиты), прикладное (текстовые и табличные процессоры, графические редакторы, САПР), инструментальное (среды программирования). Файловая система организует хранение: имя, расширение, путь, атрибуты.

# Алгоритмы

Алгоритм — точное и понятное предписание исполнителю выполнить последовательность действий для решения задачи. Свойства: дискретность, детерминированность, массовость, результативность, конечность.

Способы записи: словесный, блок-схема (начало/конец, ввод/вывод, процесс, решение, модификация), псевдокод, программа. Базовые структуры: следование, ветвление (полное и неполное), цикл (с предусловием, с постусловием, с параметром).

Типовые алгоритмы: нахождение суммы и произведения, поиск максимума, подсчёт элементов по условию, алгоритм Евклида (НОД), сортировка (метод пузырька), поиск элемента в массиве (линейный и двоичный).

# Программирование

Основные понятия: переменная, тип данных (целый, вещественный, символьный, строковый, логический), оператор присваивания, выражение, ввод и вывод. Пример на языке Python:

sum = 0
for i in range(1, 11):
    sum = sum + i
print("Сумма:", sum)

Условный оператор: if x > 0: print("положительное") elif x == 0: print("ноль") else: print("отрицательное"). Циклы: while condition: … и for i in range(n): … Функции объявляют через def, возвращают значение через return.

Работа с массивами (списками): создание, обращение по индексу, перебор, поиск, сортировка. Пример поиска максимума: maximum = a[0]; for value in a: if value > maximum: maximum = value.

# Таблицы и базы данных

Электронная таблица: ячейка, адрес (A1, B7), диапазон, формулы, абсолютные и относительные ссылки ($A$1). Функции: СУММ, СРЗНАЧ, МИН, МАКС, ЕСЛИ, СЧЁТЕСЛИ. Диаграммы строят по выделенному диапазону.

База данных — организованная совокупность данных, управляемая СУБД. Модели: иерархическая, сетевая, реляционная. В реляционной модели данные хранятся в таблицах: запись (строка), поле (столбец), ключ (уникальный идентификатор).

SQL: SELECT * FROM books WHERE year > 2020 ORDER BY title; INSERT INTO … VALUES …; UPDATE … SET … WHERE …; DELETE FROM … WHERE …. Запросы с условиями AND, OR, LIKE, а также сортировка и агрегатные функции COUNT, SUM, AVG.

# Компьютерные сети и безопасность

Сеть — соединение компьютеров для обмена данными. Классификация: локальные (LAN), городские, глобальные (WAN). Топологии: звезда, шина, кольцо. Internet — глобальная сеть на основе протоколов TCP/IP.

IP-адрес, доменное имя, DNS, протоколы HTTP/HTTPS, FTP, SMTP. Браузер, поисковые системы, электронная почта, облачные сервисы. Скорость передачи измеряется в битах в секунду.

Угрозы: компьютерные вирусы, троянские программы, фишинг, спам, вредоносные вложения. Защита: антивирус, обновления, сложные пароли, двухфакторная аутентификация, резервное копирование, осторожность с незнакомыми ссылками и вложениями. Правовые аспекты: защита персональных данных, авторское право, ответственность за неправомерный доступ к информации.
