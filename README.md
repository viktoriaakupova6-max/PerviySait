# Библиотечный фонд — сайт библиотеки лицея

Одностраничный сайт школьной библиотеки: презентация фонда, статистика,
электронный каталог с поиском и фильтрами, правила записи и контакты.

Чистый HTML + CSS + JavaScript без сборки и зависимостей — открывается прямо
в браузере или раздаётся любым статическим сервером.

## Структура

```
index.html        разметка страницы (шапка, hero, фонд, каталог, запись, контакты)
css/styles.css    все стили: палитра в :root, адаптив, prefers-reduced-motion, печать
js/data.js        данные каталога (массив window.LIBRARY_BOOKS)
js/app.js         каталог, поиск, фильтры, сортировка, модальное окно, анимации
assets/favicon.svg
```

## Как запустить

```bash
python3 -m http.server 8000
# затем открыть http://localhost:8000
```

## Что на странице

- **Первый экран** — заголовок, быстрый поиск с популярными запросами,
  декоративная полка из «корешков» книг.
- **Фонд в цифрах** — счётчики, которые анимируются при появлении в кадре.
- **О фонде** — описание, преимущества и карточка состава фонда
  (учебная, художественная, справочная литература, краеведение).
- **Каталог** — 17 изданий: поиск по названию, автору, разделу и аннотации,
  фильтр по разделам, сортировка, «показать ещё», карточка книги с шифром,
  полкой и числом свободных экземпляров, кнопка бронирования.
- **Как записаться** — три шага и часы работы.
- **Контакты** — адрес, телефон, почта и схема-заглушка вместо карты.

## Как добавить книгу

Откройте `js/data.js` и добавьте объект в массив:

```js
{
  id: 'уникальный-id',
  title: 'Название',
  author: 'Автор',
  category: 'Учебники',      // Учебники | Художественная | Справочная | Методическая | Краеведение
  year: 2024,
  publisher: 'Издательство',
  pages: 288,
  isbn: '978-5-...',
  shelf: 'У-11',             // шифр / полка
  total: 30,                 // всего экземпляров
  free: 22,                  // свободно сейчас (0 — все выданы)
  isNew: true,               // необязательно: метка «новинка»
  cover: ['#3a6f8f', '#1d455c'], // градиент обложки
  annotation: 'Короткое описание для карточки.'
}
```

Каталог, счётчики результатов и фильтры обновятся автоматически.

## Настройка под себя

- Цвета, радиусы и шрифты — переменные в начале `css/styles.css` (`:root`).
- Название библиотеки, адрес, телефон и часы работы — в `index.html`.
- Категории в фильтре — кнопки `data-cat` в блоке `#chips` и поле
  `category` в `js/data.js` (значения должны совпадать).

## Доступность и адаптив

- Семантическая разметка, `skip-link`, видимый фокус, `aria-live` для
  результатов поиска.
- Модальное окно: закрытие по Esc, ловушка фокуса, возврат фокуса на кнопку.
- Мобильное меню-бургер, брейкпоинты на 1080 / 940 / 820 / 680 / 420 px.
- Учитывается `prefers-reduced-motion`; есть стили для печати.

## Примечание

Все названия, адреса, телефоны и цифры — демонстрационные. Замените их на
реальные данные библиотеки перед публикацией.
