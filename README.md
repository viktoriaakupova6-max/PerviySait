# Библиотечный фонд — ГБПОУ «Уфимский машиностроительный колледж»

Одностраничный сайт библиотеки колледжа: презентация фонда, статистика,
электронный каталог с поиском и режим чтения книг прямо на сайте.

Чистый HTML + CSS + JavaScript без сборки и зависимостей.

## Структура

```
index.html          разметка страницы + читалка
css/styles.css      стили: палитра логотипа в :root, адаптив, print, motion-reduce
js/data.js          каталог: массив window.LIBRARY_BOOKS
js/texts.js         короткие стихотворения: window.LIBRARY_TEXTS
js/app.js           каталог, поиск, фильтры, сортировка, карточка книги
js/reader.js        режим чтения: темы, размер шрифта, прогресс, оглавление
texts/              113 файлов текстов <id книги>.txt, 42 МБ (см. texts/README.md)
assets/logo-round.png  круглый логотип колледжа (медленно крутится в шапке)
```

## Как запустить

```bash
python3 -m http.server 8000
# затем открыть http://localhost:8000
```

## Режим чтения

- Три темы: светлая, сепия, ночь (переключатель в верхней панели).
- Кнопки `A−` / `A+` меняют размер шрифта, выбор сохраняется в браузере.
- Полоса прогресса и сохранение места: при повторном открытии книга
  продолжается с того места, где читатель остановился (позиция пишется и при
  закрытии читалки).
- Оглавление по главам: «Отцы и дети» — 28 глав, «Капитанская дочка» — 14 глав
  и пропущенная глава, «Герой нашего времени» — 5 повестей и предисловие,
  «Мастер и Маргарита» — 32 главы в двух частях и т. д.
- Стрелки ← → переключают главы, Esc закрывает читалку.
- Если текст не задан — показывается подсказка, как его добавить.

## Как добавить книгу в каталог

`js/data.js`:

```js
{
  id: 'уникальный-id',            // по нему же ищется текст
  title: 'Название',
  author: 'Автор',
  category: 'Учебники',           // Учебники | Художественная | Справочная | Методическая | Краеведение
  year: 2024,
  publisher: 'Издательство',
  pages: 288,
  isbn: '978-5-...',
  shelf: 'У-11',                  // шифр / полка
  total: 30,                      // всего экземпляров
  free: 22,                       // свободно сейчас
  isNew: true,                    // необязательно: метка «новинка»
  cover: ['#3157ac', '#264796'],  // градиент обложки
  annotation: 'Короткое описание для карточки.'
}
```

демонстрационные.

## Как включить чтение книги

Вариант 1 — без правки кода: положите обычный текстовый файл
`texts/<id книги>.txt` (UTF-8, абзацы через пустую строку). Он подхватится
автоматически. Строка, начинающаяся с `# `, становится заголовком главы и
попадает в оглавление.

Вариант 2 — с разметкой глав, стихами и подзаголовками в `js/texts.js`:

```js
window.LIBRARY_TEXTS = {
  'мой-id': {
    source: 'Источник и правовой статус текста',
    chapters: [
      {
        title: 'Глава первая',
        blocks: [
          { type: 'p', text: 'Абзац прозы' },
          { type: 'verse', lines: ['Строка 1', 'Строка 2'] }, // строфа
          { type: 'subhead', text: 'Подзаголовок' }
        ]
      }
    ]
  }
};
```

> Важно: публикуйте только те тексты, на которые у библиотеки есть право
> (общественное достояние или разрешение правообладателя). Учебники и книги
> современных авторов обычно остаются только в бумажном фонде.

## Настройка под себя

- Цвета: переменные `--navy`, `--blue`, `--cyan`, `--yellow`, `--green` и
  производные от них в начале `css/styles.css`.
- Разделы каталога: кнопки `data-cat` в блоке `#chips` (index.html) должны
  совпадать с полем `category` в `js/data.js`.
- Правила выдачи и часы работы — в `index.html` (блоки «Как записаться» и
  «Часы работы»).
- Название, адрес, телефон, часы работы — в `index.html`.
- Логотип — `assets/logo-round.png` (шапка, подвал, иконка сайта).
- После правок CSS/JS меняйте `?v=N` в ссылках `index.html`, чтобы браузеры
  не показывали старую версию из кэша.
- Скорость вращения логотипа — `animation: logo-spin 32s` в `css/styles.css`.

## Доступность и адаптив

- Семантика, `skip-link`, видимый фокус, `aria-live` для результатов поиска.
- Окно издания и читалка: закрытие по Esc, ловушка фокуса, возврат фокуса.
- Брейкпоинты 1080 / 940 / 820 / 680 / 420 px, мобильное меню-бургер.
- Учитывается `prefers-reduced-motion` (анимации логотипа и полок отключаются);
  есть стили для печати.

## Примечание

Телефон, почта и цифры фонда — демонстрационные, замените их на реальные
данные библиотеки перед публикацией.
